# The public keys a release build trusts for updates. The release workflow reads this file into
# NEXUS_UPDATER_PUBKEY, and refuses to build while it lists no key.
#
# One key per line: the base64 of a minisign public key file (`base64 < minisign.pub`, on one line).
# The first line is the active key, which signs releases. The second is the next key. Its secret half stays offline
# until a rotation, so builds that already trust it update without a gap.
#
# Lines that start with `#` are comments. A change to this file changes whose updates every later build installs:
# review it as you review a change to the release workflow.
