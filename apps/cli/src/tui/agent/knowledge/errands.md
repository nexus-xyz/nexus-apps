# The assistant's errands

An errand is a job the person handed their assistant, Nexus. It is not yours: you are the coding agent of this session.
Read this page when the person asks about errands, the Errands view, or errands in projects.

## Errands

- Errands are off by default. With them on, the sidebar lists the open errands under the Assistant row.
- With errands on, ⇧⌘J opens the Errands view with a New errand box. The errand starts from the person's text.
- In the Assistant pane, each errand is its own thread, under Errands.
- The person replies there with "Reply about <errand>". Its ⋯ menu renames, pins, marks done or archives it.
- In Nexus for desktop, ⋯ › Hand off to a session opens a New session draft with the errand in it. Nothing sends.
- Closed and archived errands are in the errand History, which the person can search.

## Errands on the phone

- With errands on, Nexus for iPhone and Android shows them as a row of pills over the Assistant.
- A tap opens the errand's thread. A long press opens Pin, Rename, Move to project, Mark done and Archive.
- "I opened an errand for this." in the thread shows the errand's card, which opens its thread.

## Errands in projects

- In Nexus UI, the person can file an errand in a project: drag its sidebar row onto the project, or use ⋯ › Move to project.
- In Nexus for desktop, ⋯ › Move to project files it. There is no drag yet.
- A project lists its errands under it in the sidebar. Its page has "Ask Nexus about <project>", which starts an errand there.
- A project holds one organization's errands only. The sidebar shows the loose errands under the Assistant and "N in projects".
- A project can be a Gateway project, which groups repositories and people. The person sees only the projects they are in.
- A project of errands only has a name. When a Gateway project has the same name, the person can link them.
- A note in memory can belong to a project. Only an errand filed in that project reads it.
- An errand filed in a Gateway project reads its repositories. With GitHub connected, Nexus reads their files as the person.
- With Gateway projects off, every project is a name, as before.
- In Nexus UI, a project's page shows its chats, its Artifacts and files, and "What Nexus knows here".
- Its chats are its errands and the sessions they set up. Its files come from its Gateway project's repositories.
- On that page the person adds, edits and forgets the project's notes. Move to project lists the Gateway projects too.

## Hand an errand off to a session

- In Nexus UI, an open errand's ⋯ menu has Hand off to a session.
- It opens New session with the errand in the box: its goal, constraints, steps so far and last replies.
- Nothing sends until the person sends it. The errand then shows the step "Handed off to a session", with the session's link.
